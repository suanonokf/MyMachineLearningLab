# Machine Learning and Deep Learning Portfolio

This repository contains a collection of Jupyter notebooks demonstrating the implementation of various machine learning and deep learning algorithms, ranging from fundamental linear models to advanced neural network architectures.

## Project Overview

The project serves as a comprehensive learning path and implementation guide for AI/ML, covering data preprocessing, classical machine learning, and modern deep learning using PyTorch.

## Notebook Contents

### Classical Machine Learning
- **`linear_regression.ipynb`**: Implementation of Linear Regression to predict house prices using real estate data. Includes data visualization and evaluation metrics (MSE, MAE).
- **`logistic_regression.ipynb`**: A from-scratch implementation of Logistic Regression used for binary classification on fertility data, featuring manual gradient descent and sigmoid activation.
- **`gradien_descent_impl.ipynb`**: A detailed implementation of the Gradient Descent algorithm for optimizing linear models.

### Deep Learning with PyTorch
- **`cnn.ipynb`**: 
    - Implementation of a **Convolutional Neural Network (CNN)** for image classification on the CIFAR-10 dataset.
    - Advanced implementation of **ResNet-18** from scratch, demonstrating residual connections and deep architecture.
- **`transformer_encoder.ipynb`**: 
    - A from-scratch implementation of the **Transformer Encoder** architecture.
    - Includes Multi-Head Attention, Positional Encoding, and Feed-Forward Networks.
    - Demonstrated on a sentiment analysis task (text classification).
- **`pytorch_tuto.ipynb`**: An introductory guide to PyTorch, covering tensor operations, CUDA setup, and dataset loading.

### Data Handling & Visualization
- **`panda.ipynb`**: Exploratory data analysis and manipulation using the Pandas library.
- **`data_visualization.ipynb`** & **`data_visualization2.ipynb`**: Demonstrations of data visualization techniques using Matplotlib and other libraries.

## Technologies Used
- **Language**: Python
- **Libraries**: 
    - `PyTorch` (Deep Learning)
    - `Scikit-Learn` (Classical ML)
    - `Pandas` (Data Manipulation)
    - `NumPy` (Numerical Computing)
    - `Matplotlib` (Visualization)

## Key Highlights
- **From-Scratch Implementations**: Many algorithms (Logistic Regression, Gradient Descent, Transformer Encoder) are implemented without high-level ML libraries to demonstrate a deep understanding of the underlying mathematics.
- **Deep Learning Architectures**: Covers both CNNs for spatial data (images) and Transformers for sequential data (text).
- **Real-world Data**: Utilizes datasets like CIFAR-10 and real estate data for practical application.
